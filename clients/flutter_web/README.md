# AIXianlu Flutter Web Client

目标主站前端（Phase 2）。

## 规划页面

1. **首页 / 实时信誉榜**  
   极客深色风格，运营商（电信/联通/移动）+ AI 工具双维度筛选。

2. **详情 / 决策页**  
   深度评测、客观优缺点、实测数据、风险雷达、带 Affiliate 参数的购买按钮。

3. **探针下载页**  
   引导用户下载本地测速工具并贡献数据。

## 技术栈

- Flutter Web
- 对接当前 proxy-atlas API 或未来 Drupal JSON:API
- 部署目标：Cloudflare Pages
